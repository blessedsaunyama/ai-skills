- Blender VSE projects are rendered by Blender and compared with the final MP4 (Standard colour transform for editing)
- README with install for Claude Code, claude.ai and other agents

- Wizard: Output question (MP4 / project / both), editor choice and install flow; same flow for missing engine tools; setup_check.py uses the registry

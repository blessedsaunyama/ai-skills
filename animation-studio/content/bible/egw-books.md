# EGW books: codes, where to read them, and which Bible stories they cover

**Reference format:** `CODE page.paragraph`, e.g. `PK 543.2` = *Prophets and Kings*, page 543, paragraph 2. Copy codes exactly as `tools/egw_fetch.py` prints them. Never build a code from memory.

**Online text:** `https://text.egwwritings.org/book/b<ID>` is the table of contents, and `https://text.egwwritings.org/read/<ID>.<para>` is a chapter. The main `egwwritings.org` app and WebFetch often get **HTTP 403**. Use `python3 tools/egw_fetch.py <chapter link or id>`, which works and prints every paragraph with its code. If it also fails: search for the chapter, try again, and if it still fails mark every EGW item **UNVERIFIED** (or leave it out).

Book titles and IDs below were checked against text.egwwritings.org on 2026-11-04.

## Quoting rules
- Quote only text printed by `egw_fetch.py` (or a page you actually loaded), word for word, with its code. Shorten only with "..." and never change the meaning.
- Per the user's preference, EGW references **don't appear inside the video**. They go in `study-notes.md` and in the "Further reading" line of the video description. An end card ("Further reading: *Prophets and Kings*, ch. 44") only if the user asks. Never as a narrator mention.
- EGW supports and comments. It never supplies "facts" that appear in narration as if they were Scripture. If a script line depends on an EGW detail, tag it 📚 with the code, and keep it out of 📖 lines.

# Worked example: Daniel in the lions' den (kids, 60 s, 9:16 + 16:9 FAST)
Shows exactly what Stages 1–6 of SKILL.md produce. Every quote was checked against the KJV text fetched into `scripture.md`, and every EGW quote was printed by `tools/egw_fetch.py`.

| File | Stage | What it is |
|---|---|---|
| `brief.md` | 1 | Intake answers + discussion questions (Stage 8 extra) |
| `scripture.md` | 3 | Daniel 6 KJV, verbatim from BibleGateway |
| `script.txt` | 4 | Narration only (paste into ElevenLabs) |
| `fidelity.md` | 4 | Fidelity table + accuracy notes |
| `shotlist.md` | 5 | Shot list for FAST mode, safe-box notes, reverence check |
| `study-notes.md` | 6 | Key verses, cross-references, EGW quotes with codes (not in the video) |
| `description.txt` | 6 | Ready-to-paste video description with the "Further reading" line |

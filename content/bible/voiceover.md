# Voiceover: ElevenLabs or the user's own voice

The user records the narration and uploads it, and the picture is timed to it. Claude can't hear audio, so always keep the **exact final script text** as recorded. If the user changed any words while recording, ask for the new text.

## Hand-off message (send with the script package)
> Paste the narration block into ElevenLabs (or read it yourself), export **mp3 or wav without music**, and upload it here with any wording changes. I'll make the video from it.

## ElevenLabs settings (starting point)
- Voice: one warm, steady storyteller voice. For children, a friendly, clear voice; for congregations, a calm, mature narrator.
- Speed about 0.95–1.05 (slower for young children), stability about 45–60 %, similarity about 75 %, style low (0–15 %).
- Generate per paragraph if a long read drifts, then join the clips without music.
- Quoted KJV lines: put them in their own sentence so the voice slows naturally. ElevenLabs reads "thee", "thou", "hath" fine.
- Pronunciation: if a name comes out wrong, respell it **in the ElevenLabs box only** (the skill's script.txt keeps the real spelling for timing).

## Own voice
Use a quiet room with soft furnishings and hold the phone 20–30 cm away (any voice-memo app is fine). Leave a short pause at each full stop, don't add music, and re-record a sentence rather than editing words.

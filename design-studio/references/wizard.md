# Wizard question texts

Ask only what the request did not already say. One question per message. Multiple choice
where possible; the user can always type their own answer. Plain, simple language.

1. **Type** – "What are we making?" Event flyer · Poster · Banner / roll-up · Social post · Certificate · Thumbnail · Logo
2. **Event details** – ask together as one short form if the tool allows, otherwise one by one:
   event name · date · start time · end time (optional) · venue · host line ("e.g. MSU SDA presents") · guest speaker name and role.
   Put their text on the design exactly as written (any language): don't translate or reword unless asked.
3. **Assets** – "Please put your files in these folders inside <project>: `logos/` (PNG with transparent
   background is best), `photos/` (real photos only), `reference/` (optional: designs you like the feel of).
   Tell me when done." Then scan and list back: name, size, transparent yes/no, notes.
   If a speaker photo is a normal photo: "Shall I cut out the background of <file>? (free, offline)".
4. **Logo placement** – for each logo: top-left · top-center · top-right · center (big) · bottom-left · bottom-center · bottom-right.
5. **Contacts** (multi-select) – Phone · WhatsApp · Email · Facebook · Instagram · TikTok · YouTube · X · Website. Then ask each value.
6. **Size** – show ratio + pixels. Common choices:
   - A4 flyer (210 x 297 mm · 2480 x 3508 px) – print
   - 9:16 story / WhatsApp status (1080 x 1920 px)
   - 1:1 square post (1080 x 1080 px)
   - 4:5 portrait post (1080 x 1350 px)
   - 16:9 landscape / YouTube thumbnail (1920 x 1080 / 1280 x 720 px)
   - A3 poster · roll-up 85 x 200 cm · Facebook cover 2.63:1 (1640 x 624 px) · more… (sizes.md)
   Then "Portrait or landscape?" for rectangles, and for print: "Add 3 mm bleed? Crop marks?"
7. **Look** – Brand (saved brands list) or colours ("use my logo's colours" → palette tool) or mood ·
   Fonts: Montserrat + Open Sans (modern) · Playfair Display + Lato (elegant/formal) · Bebas Neue + Poppins (bold/youthful) · Choose for me ·
   Style: formal · modern · youthful · elegant
8. **Anything else?** – free text: extra lines, a paragraph, bullet points, call to action, things to avoid.
9. **Plan card** → Start · Change something · Give me 3 variations.

After delivery: "Want this in another size too?" and "Save these colours/logos as a brand for next time?"

# Document types, formats and layouts

## Which format suits which type (suggest this; the user decides)
| Type | Natural format(s) | Typical length | Structure (after the automatic Summary) |
|---|---|---|---|
| Study / lesson | PDF + DOCX | 3-6 pages | memory verse or aim → 3-5 numbered points (heading, explanation, callouts) → application → questions → references |
| Report | DOCX + PDF | 4-15 pages | `toc` (if > 6 pages) → introduction → background → findings → discussion → conclusion/recommendations → references |
| Essay | DOCX | 2-6 pages | introduction (thesis) → 3-5 body sections (claim, evidence, analysis) → conclusion → references |
| Notes / handout | PDF | 1-4 pages | short headed sections, bullets, tables, key terms table |
| Newsletter | PDF (screen) or DOCX | 1-4 pages | highlights → 2-4 stories → events table → notices → contacts |
| Slides | PPTX (+ PDF handout) | 8-20 slides | title → summary → sections → recap → references |
| Worksheet | DOCX + PDF | 1-3 pages | instructions → tasks (questions with `lines`) → challenge → answer key (optional) |
| Quiz | XLSX + CSV (+ PDF to print) | 10-30 questions | instructions → questions → answer key / marked sheet |
| Plan / tracker | XLSX (+ CSV) | 1-4 sheets | Summary sheet → plan table (task, owner, start, due, status) → budget with totals |
| CV | DOCX + PDF | 1-2 pages | name and contacts → profile → experience → education → skills → referees (user's real details only) |

Lengths: about 450 words per A4 page of body text (less with boxes and tables). A slide ≈ 30-60 words.

## Themes
| Theme | Feel | Default for |
|---|---|---|
| `classic` | navy + gold, serif headings | general, business |
| `modern` | clean sans, teal/blue | health, tech |
| `church` | deep purple + gold, serif headings | SDA/Church |
| `school` | green + amber, friendly sans | education |
| `minimal` | black and grey | CVs, formal letters |

`style: "print"` (default): ink-saving colours, white background, readable in black and white, A4 margins 20 mm.
`style: "screen"`: brighter colours, slightly larger text, for phones/WhatsApp/laptops (PDF links stay clickable in both).

A brand (`"brand": "id"`) overrides the theme's primary and accent colours and adds its logo and contacts.

## Page sizes
A4 (default), A5 (booklets, church bulletins), Letter (USA/Canada), Legal. `"orientation": "landscape"` for wide tables and trackers.

## Writing well (all types)
- Lead with the point; short paragraphs (2-4 sentences); one idea per bullet.
- Headings say what the section shows ("Rest was built into creation", not "Section 2").
- Tables for comparisons, numbered lists for steps, callouts for warnings/tips/"your turn".
- Audience words: children → short sentences, everyday words; professionals → precise terms.
- Shona documents: write natively in Shona (not word-for-word from English); keep names and Bible references in their Shona forms when using a Shona Bible (e.g. "Johani 3:16").
